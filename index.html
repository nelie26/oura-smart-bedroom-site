PERSONAL TECHNOLOGY PROJECT

Oura Smart Bedroom Monitor

A personal wellness and recovery monitoring project integrating Oura Ring data with a custom-built dashboard.

About the Project

This project explores the integration of wearable health technology, embedded systems, and software development to create a personalized recovery monitoring experience.

Features

Daily readiness and recovery monitoring.

Sleep duration and sleep-stage visualization.

Heart rate variability and resting heart rate tracking.

Personal wellness trends and insights.
