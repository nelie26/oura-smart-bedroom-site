Privacy Policy

Last updated: November 21, 2026

This Privacy Policy explains how the Oura Smart Bedroom Monitor project handles information. This is an independent, personal wellness technology project and is not affiliated with or endorsed by Oura.

1. Information We Access

The current prototype uses sample data and does not retrieve actual Oura account information.

When Oura API integration is enabled, the application is intended to access authorized wellness information such as daily readiness, sleep summaries, heart rate variability, and heart-rate measurements, depending on the permissions granted by the user.

2. How Information Is Used

Information accessed through the Oura API is intended solely to display personal wellness measurements, recovery summaries, and trends within the dashboard.

3. Storage and Security

The application is designed to process information through a locally operated Python backend. API credentials and authorization tokens should be stored securely and must never be included in public source code.

The current prototype does not require actual Oura health data. Any future storage, retention, or backup practices will be documented before those features are enabled.

4. Sharing of Information

The project is intended for personal use. It is not designed to sell personal information or share wellness measurements with advertisers.

5. Third-Party Services

The application may communicate with Oura services through the official Oura API when authorized. Oura's own privacy practices apply to information processed by Oura.

6. User Control

Users can manage or revoke the application's access through their Oura account. Locally stored application data can be deleted from the device where it is stored.

7. Changes to This Policy

This policy may be updated as the project develops, particularly when new data-processing or storage features are introduced.
